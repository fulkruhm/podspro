# Documentation Index

This repository uses a two-lane documentation model.

- `docs/current/`: actively maintained documents that describe the current product and runtime behavior.
- `docs/archive/`: historical or exploratory documents kept for reference.

## Standards

- Update `README.md` and `TECHNICAL_SYSTEM_HANDBOOK.md` in the same PR as any behavior/API change.
- If a document becomes historical, move it to `docs/archive/` in a follow-up PR.
- Keep runbooks task-oriented and validated quarterly.
